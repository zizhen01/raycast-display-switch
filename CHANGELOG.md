# Display Switch Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Toggle Mirror, Mirror Displays, Extend Displays and Swap Main Display commands
- Manage Displays list and Display Status menu bar item
- Preferences for which display to optimize mirroring for and which display is main when extended
- Optional: audio output follows the main display, dim the built-in display while mirrored, auto-extend when macOS mirrors by itself

## [Mirror in Either Direction] - {PR_MERGE_DATE}

- Manage Displays can now mirror any display onto any other. It previously only offered the direction set in preferences, which left no way to mirror the external display onto the built-in one.
